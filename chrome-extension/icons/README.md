# Icons Directory

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

You can create these using any image editor or use a placeholder image for development.

Suggested design: Shield icon with checkmark or "V" for VerifiAI.
