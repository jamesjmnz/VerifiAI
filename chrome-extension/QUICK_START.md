# Quick Start Guide

## Step 1: Generate Icons (Required)

1. Open `generate-icons.html` in your browser
2. Click "Generate Icons"
3. Right-click each icon and save as:
   - `icons/icon16.png`
   - `icons/icon48.png`
   - `icons/icon128.png`

**OR** use any image editor to create 16x16, 48x48, and 128x128 PNG files and save them in the `icons/` folder.

## Step 2: Load Extension in Chrome

1. Open Chrome
2. Go to `chrome://extensions/`
3. Enable **"Developer mode"** (toggle sa top-right)
4. Click **"Load unpacked"**
5. Select the **`chrome-extension`** folder (yung folder mismo, hindi yung files inside)

## Step 3: Configure API URL

1. Click the extension icon sa Chrome toolbar
2. Enter your backend API URL (default: `http://localhost:8000`)
3. Click "Save Settings"

## Step 4: Test on Facebook

1. Go to `facebook.com`
2. Look for **"Fact Check"** buttons sa posts
3. Click to verify any post!

---

**Note:** Make sure your backend is running before testing!
